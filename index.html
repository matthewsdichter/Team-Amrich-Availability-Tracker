Marking a space writes a small status file back to the tracker's repository, so everyone on the team sees the change. That needs a GitHub token with write access to this one repo. Reading the site never needs one.

  1. Open GitHub → fine-grained tokens.
  2. Repository access → Only select repositories → Team-Amrich-Availability-Tracker.
  3. Repository permissions → Contents: Read and write.
  4. Set an expiry you're comfortable with, generate, and paste it below.

Stored in this browser only — never sent anywhere but GitHub. Anyone who can use this computer can read it, so skip this on a shared machine, and revoke the token on GitHub if it ever gets out.
